This is a placeholder post in English. Posts written in English live under `/en/blog/`, while Chinese posts live under `/blog/`. Both lists show every post, with a small tag when a post is in the other language.

## Writing

Drop a folder into `posts/` with an `index.md` and its images, then push. GitHub Actions builds the site and publishes it to GitHub Pages.

```bash
git add posts/my-post
git commit -m "docs(blog): add my post"
git push
```

That's it.
